POSEIDON

POSEIDON is a water utility management system built for municipal waterworks: consumer accounts, meter reading, billing, collection, reports, GIS mapping and a mobile app for residents. It is developed by Vivito IT Solutions for, and operated by, the local government units it serves.

POSEIDON Backups

POSEIDON Backups is the tool POSEIDON's server uses to keep an off-site copy of its automatic database backups in Vivito IT Solutions' Google Drive. It only creates and updates its own backup files there and cannot see any other files. See the privacy policy.
